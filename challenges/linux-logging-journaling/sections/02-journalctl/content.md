# Systemd Journal Management with Journalctl

Modern Linux distributions running systemd use `systemd-journald` to capture log data from the kernel, init scripts, standard outputs of services, and syslog events in a structured binary format.

## 1. Querying by Service Unit (`-u`)

To inspect logs generated by a specific systemd service unit:

```bash
journalctl -u nginx.service
```

## 2. Filtering by Time Windows (`--since` / `--until`)

Filter journal entries by explicit timestamps or relative time strings:

```bash
journalctl --since "2026-09-20 10:00:00" --until "2026-09-20 12:00:00"
journalctl -u nginx --since "1 hour ago"
```

## 3. Filtering by Boot Sessions (`-b`)

- `journalctl -b` or `journalctl -b 0`: Logs from the current system boot.
- `journalctl -b -1`: Logs from the previous system boot session.

## 4. Priority Levels (`-p`)

Filter logs by Syslog severity levels (0: emerg, 1: alert, 2: crit, 3: err, 4: warning, 5: notice, 6: info, 7: debug):

```bash
journalctl -p err
```

## 5. Output Formatting (`-o`)

Export structured data in JSON format for automated processing:
```bash
journalctl -u nginx -o json-pretty
```
