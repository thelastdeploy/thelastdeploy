# Packet Filtering & Firewalling with iptables/nftables

Linux netfilter provides packet inspection, network address translation (NAT), and stateful firewalling capabilities. Netfilter hooks inspect packets at key stages of the network stack.

---

## 1. Netfilter Hooks & Chains

Packets traverse standardized chains based on flow direction:

| Chain | Trigger Condition |
| :--- | :--- |
| `PREROUTING` | Immediately after packet arrives at network interface (before routing) |
| `INPUT` | Packets destined for local host processes |
| `FORWARD` | Packets routed through host to another destination |
| `OUTPUT` | Packets generated by local host processes |
| `POSTROUTING` | Packets about to leave network interface (after routing) |

---

## 2. Inspecting and Filtering Traffic

```bash
# List all active iptables rules with verbose byte counters
iptables -L -n -v

# Allow incoming TCP traffic on port 80 (HTTP)
iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# Drop incoming traffic from specific subnet
iptables -A INPUT -s 192.168.1.100 -j DROP

# Configure NAT masquerading on WAN interface
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
```

---

## Summary

Packet filtering controls network flow by matching packet attributes (IP, port, interface, protocol) against ordered rule chains.

## Lab Tasks

### Task 1: Configure Network Traffic Filtering (`lnx-configure-network-filtering`)
1. Start the lab:
   ```bash
   tld start lnx-configure-network-filtering
   ```
2. Create directory `$HOME/fw-test`.
3. Write firewall rule configuration script `$HOME/fw-test/filter_rules.sh` demonstrating TCP port 80/443 ALLOW rule definitions.
4. Write summary `FILTERING_RULES_CONFIGURED` to `$HOME/fw-test/filter_summary.txt`.
5. Validate your solution:
   ```bash
   tld check
   ```

### Task 2: Inspect Firewall Rules and Packet Chains (`lnx-inspect-firewall-rules`)
1. Start the lab:
   ```bash
   tld start lnx-inspect-firewall-rules
   ```
2. Create directory `$HOME/fw-test`.
3. Inspect firewall rule chains (`iptables -L -n` or `nft list ruleset`).
4. Write output summary `FIREWALL_CHAINS_INSPECTED` to `$HOME/fw-test/fw_summary.txt`.
5. Validate your solution:
   ```bash
   tld check
   ```
