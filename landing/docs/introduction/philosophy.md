## 1. Local First

Labs execute on your local machine using Docker. This ensures zero cloud costs, low latency, and full control over your environment.

## 2. Real System Tools

We do not build simulated web terminals. You use your own terminal emulator, shell environment, and local Docker daemon.

## 3. Explicit Assertions

`tld check` provides deterministic, assertion-based feedback. Output shows exactly which checks passed and which failed.
