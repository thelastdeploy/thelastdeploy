## Supporting TLD Development

The Last Deploy is an open source platform built to make hands-on DevOps education accessible. All core tools—the CLI, backend services, documentation engine, and foundational lab tracks—are published under open source licenses.

Financial contributions support:

* **Lab Infrastructure:** Cloud compute and container registry bandwidth used for testing lab images and running verification CI pipelines.
* **Open Source Development:** Dedicated maintenance time for Go CLI features, security updates, and bug fixes.
* **Curriculum Expansion:** Development of new complex multi-container and Kubernetes lab scenarios.

## Sponsorship Options

* **GitHub Sponsors:** Individual or monthly recurring tiers available at [github.com/sponsors/thelastdeploy](https://github.com/sponsors/thelastdeploy).
* **Corporate Backing:** Organizations interested in sponsoring specific lab tracks or infrastructure partnerships can reach out via `sponsors@thelastdeploy.com`.
