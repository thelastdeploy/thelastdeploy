## Server & Channels

The TLD Discord server is used for technical assistance with labs, debugging environment issues, and discussing project development.

* **Invite Link:** [discord.gg/thelastdeploy](https://discord.gg/thelastdeploy)

### Key Channels

| Channel | Purpose |
| :--- | :--- |
| `#announcements` | CLI releases, infrastructure updates, and new lab drops. |
| `#lab-help` | Troubleshooting broken labs or validation script failures. |
| `#cli-dev` | Go CLI, Docker SDK, and backend API technical discussions. |
| `#lab-authors` | Guidelines and feedback on creating new lab scenarios. |
| `#general-chat` | General DevOps, Linux, and cloud infrastructure discussions. |

## Asking for Lab Help

When requesting help in `#lab-help`, provide concrete environment details to avoid unnecessary back-and-forth:

1. **CLI Version:** Output of `tld version`.
2. **Doctor Status:** Output of `tld doctor`.
3. **Lab ID:** The exact lab slug (e.g., `linux-file-permissions`).
4. **Error Logs:** Copy of the terminal error or `tld check` failure output.
