---
title: "tld version"
description: "Print CLI agent version and system architecture."
section: "CLI"
---

`tld version` prints the current binary version, target OS architecture (`amd64`/`arm64`), and release build commit tag.

## Usage

```bash
tld version
```

## Example Output

```text
tld version v1.1.0 (linux/amd64)
```
