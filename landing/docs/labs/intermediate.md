## Intermediate Challenges

* **Nginx Reverse Proxy Misconfiguration (`nginx-reverse-proxy`):** Fix broken upstream proxy passes and HTTP header forwarding in Nginx. (Track: Nginx, 20 min, 35 XP)
* **Container Bridge Networking (`dkr-bridge-networking`):** Resolve inter-container DNS and network routing failures. (Track: Docker, 25 min, 40 XP)
* **Fix CrashLoopBackOff Pod (`k8s-pod-crashloop`):** Analyze pod termination logs and fix environment configuration errors in Kubernetes. (Track: Kubernetes, 25 min, 45 XP)
