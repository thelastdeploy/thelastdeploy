## Beginner Challenges

* **Filesystem Navigation (`lnx-basic-navigation`):** Navigate Linux directory structures, locate configuration files, and search logs. (Track: Linux, 10 min, 15 XP)
* **Fix File Permissions (`lnx-file-permissions`):** Troubleshoot a deployment script failing due to invalid executable permissions. (Track: Linux, 15 min, 20 XP)
* **Fix a Stopped Container (`dkr-fix-stopped-container`):** Diagnose why a web container exits immediately upon boot. (Track: Docker, 10 min, 15 XP)
* **Fix a Broken Dockerfile (`dkr-fix-broken-dockerfile`):** Correct syntax and directive errors in a Dockerfile. (Track: Docker, 15 min, 25 XP)
* **Undo Commit (`git-undo-commit`):** Revert an accidental git commit while preserving working directory changes. (Track: Git, 10 min, 15 XP)
