TLD labs are hands-on scenarios designed to test infrastructure troubleshooting and configuration skills.

## Structure

Challenges follow a four-tier taxonomy:

```text
Track (Linux, Docker, Git, Kubernetes, Nginx, Terraform)
  └── Module (e.g., linux-fundamentals, docker-containers)
        └── Section (e.g., 01-what-is-linux, 05-file-operations)
              └── Lab Challenge (e.g., lnx-file-permissions)
```

## Difficulty Tiers

* **Foundational / Beginner (5-15 min):** Single-concept challenges (permissions, service restarts, syntax fixes).
* **Intermediate (15-30 min):** Multi-container setups, network routing, service dependencies, log analysis.
* **Advanced (30-60 min):** Multi-service incidents, kernel resource limits, systemd failures, state recovery.
