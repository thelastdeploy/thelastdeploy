## Overview

The Last Deploy (TLD) is an open source hands-on DevOps platform. Everyone participating in TLD repository discussions, pull requests, Discord channels, and issue tracking is expected to adhere to basic standards of professional collaboration.

## Expected Behaviors

* **Technical, constructive feedback:** Focus code reviews on technical implementation, code safety, performance, and correctness. Provide actionable suggestions with code examples when proposing changes.
* **Respectful communication:** Maintain clarity and patience when helping maintainers or users debug environment problems.
* **Direct issue reproduction:** When opening or commenting on issues, provide concrete evidence (terminal logs, command flags, OS details, container states) rather than vague claims.
* **Acknowledge boundaries:** Maintainers and contributors work asynchronously across global time zones. Allow time for reviews and responses.

## Unacceptable Behaviors

* Harassment, derogatory comments, or personal attacks in issue threads or pull requests.
* Publishing another person's private information (such as internal API keys, passwords, or personal email addresses) without permission.
* Spreading deliberate misinformation regarding project security or licensing.
* Persistent off-topic spam or promotional links.

## Enforcement

Maintainers reserve the right to edit, decline, or close pull requests, issues, or Discord messages that violate these community standards. Severe or repeated violations will result in temporary or permanent suspension from TLD GitHub repositories and Discord servers.

To report a violation, email `community@thelastdeploy.com` with direct links to the relevant comment, PR, or message. Reports are handled privately by project maintainers.
